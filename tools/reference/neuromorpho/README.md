# Reconstrucciones de NeuroMorpho.Org

Archivos SWC en versión CNG descargados el 2026-11-19 desde NeuroMorpho.Org mediante su API pública y las URL
de archivo (sin raspar páginas). Licencia: CC BY 4.0 (https://neuromorpho.org/useterm.jsp). `meta.json` guarda,
por célula, el nombre y el ID en NeuroMorpho, especie, región, tipo, integridad física y DOI/PMID del artículo
original. Citas obligatorias al usarlas: el artículo original de cada célula; NeuroMorpho.Org (RRID:SCR_002145);
Tecuatl C, Ljungquist B, Ascoli GA (2024) FASEB Bioadv 6(7):207-221, doi:10.1096/fba.2024-00048.

No se publican estos archivos: `tools/import-neuromorpho.mjs` los convierte a `apps/web/public/atlas/neurons/`.
Ver ADR-0013.
