# Investigación y cobertura

## Escalera de verificación

Cada etapa exige evidencia propia; ninguna asciende automáticamente (plan, 05-fuentes §4):

**fuente candidata → metadatos verificados → contenido inspeccionado → afirmación extraída (con localizador) →
revisión experta → publicación**

## Carpetas

- `metadata-checks/` — respuestas de Crossref guardadas por `npm run sources:verify-doi` (auditoría).
- `protocols/` — protocolos de búsqueda por unidad.
- `evidence/` — tablas de trabajo de extracción (WP-010, WP-012).
- `assets/` — evidencia de licencias de assets (WP-020 y siguientes).
- `ontology-checks/` — auditorías de vínculos con ontologías (WP-013).
