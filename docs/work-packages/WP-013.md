# WP-013: Referencias externas verificadas (UBERON) para entidades

- **Hito:** M2 · **Ejecutor recomendado:** M · **Depende de:** — · **Tamaño:** M

## Objetivo

Añadir a las entidades `externalRefs` de UBERON verificadas contra la API de OLS (EMBL-EBI), con auditoría
guardada, y una herramienta de consulta reutilizable.

## Contexto

`Entity.externalRefs` existe pero está vacío: el plan exige verificar cada vínculo con ontologías
individualmente (ADR-0003). UBERON describe clases anatómicas multiespecie: un vínculo indica "esta entidad es
una instancia de la clase", no equivalencia entre especies.

## Archivos

- Leer: `AGENTS.md`, `packages/data-pipeline/src/cli.ts`, `packages/data-pipeline/src/verify-doi.ts` (patrón a
  imitar), `content/entities/*.yaml`, `packages/schemas/src/knowledge.ts` (`Entity.externalRefs`).
- Crear: `packages/data-pipeline/src/ontology-lookup.ts` (+ prueba con respuesta simulada, sin red),
  subcomando `ontology-lookup <término>` en `cli.ts`, script `ontology:lookup` en `package.json` raíz,
  auditorías en `docs/research/ontology-checks/`.
- Modificar: `content/entities/visual-pathway.yaml` y `content/entities/neocortex-laminar.yaml`.
- No tocar: esquemas, interfaz.

## Pasos sugeridos

1. Implementar la consulta a `https://www.ebi.ac.uk/ols4/api/search?q=<término>&ontology=uberon&exact=true`
   (u otro endpoint documentado de OLS4), que imprima candidatos (ID, etiqueta, sinónimos, definición) y guarde
   la respuesta con fecha en `docs/research/ontology-checks/`.
2. Para cada entidad: buscar; si hay **una** coincidencia clara de etiqueta/definición, añadir
   `{ system: UBERON, id: 'UBERON:XXXXXXX', version: <release de UBERON en la respuesta>, verified: true, verifiedOn: <fecha> }`.
3. Coincidencias ambiguas: no añadir; listarlas en la entrega.

## Criterios de aceptación

- Cada `externalRef` añadida tiene su auditoría JSON con la respuesta de OLS que la respalda.
- La prueba del módulo no usa red (respuesta simulada) y comprueba el análisis de resultados.
- `npm run check` en verde; `npm run boundaries` sin violaciones (fetch nativo de Node; sin dependencias nuevas).
- Entrega con la lista de entidades sin vínculo y por qué.
