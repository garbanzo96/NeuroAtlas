# WP-033: Renderizar ecuaciones con KaTeX (carga diferida)

- **Hito:** M4 · **Ejecutor recomendado:** M · **Depende de:** — · **Tamaño:** S

## Objetivo

Mostrar las ecuaciones de la ficha del modelo con notación matemática legible, sin aumentar el bundle inicial.

## Archivos

- Leer: `AGENTS.md`, `apps/web/src/components/ModelCard.tsx`, `content/models/hh-classic.yaml` (campo `latex`),
  `apps/web/package.json`, `e2e/app.spec.ts`.
- Crear: `apps/web/src/components/Equation.tsx`.
- Modificar: `ModelCard.tsx`, `apps/web/package.json` (dependencia **autorizada**: `katex`), `e2e/app.spec.ts`.
- No tocar: contenido, contratos, otros paquetes.

## Requisitos

- `Equation` importa `katex` y su CSS con `import()` dinámico (nada de KaTeX en el chunk inicial).
- `throwOnError: false`; si falla, mostrar el código LaTeX.
- Accesibilidad: el código LaTeX original disponible (p. ej. en `<details>` o `aria-label`).
- Sin fuentes ni scripts desde CDN.

## Criterios de aceptación

- `npm run build`: el JS inicial no crece más de 5 KB gzip; KaTeX en un chunk aparte.
- e2e: abrir la ficha del modelo en la escena de excitabilidad muestra elementos `.katex`.
- `npm run check` y `npm run e2e` en verde.

Ejecuta npm run check y npm run e2e y entrega diff, tamaños de bundle antes/después y salida de las comprobaciones.
