# WP-083a · Integrar las ilustraciones base en la interfaz

- **Ejecutor:** Codex · **Depende de:** ilustraciones en `apps/web/public/atlas/img/` (con `manifest.json`)

## Objetivo

Usar las 12 ilustraciones generadas (plan §7) donde rinden más, sin recargar la interfaz.

## Archivos autorizados

`apps/web/src/atlas/ui/ScaleRail.tsx`, `ui/InfoSheet.tsx` (solo `LevelSheet`), `ui/Credits.tsx`,
`AtlasApp.tsx` (aviso de nivel `LevelToast` y pantalla de carga), `atlas.css`, `apps/web/index.html`.

## Requisitos

1. **Riel**: cada nivel muestra su ícono `nivel-<id>.webp` (≈22–28 px) junto al nombre; el activo a plena
   luz, el resto tenue; transición suave. Con mezcla `mix-blend-mode: screen` el negro desaparece.
2. **Aviso de nivel** (`LevelToast`): el ícono del nivel grande (≈72 px) aparece con un fundido y una escala
   suave sobre el título.
3. **Lámina del nivel**: cabecera con el ícono del nivel a la derecha, grande y tenue, como marca de agua
   luminosa (`screen`), sin tapar texto.
4. **Pantalla de carga** (`na-boot`): fondo `bg-carga.webp` cubriendo, con un pulso lento.
5. **Metadatos**: `og:image` y `twitter:image` con `compartir.webp` (URL relativa a la base), `og:title`,
   `og:description` en español.
6. **Créditos**: sección «Ilustraciones» que diga que son esquemas generados con IA (OpenAI), no anatomía, con
   enlace a `atlas/img/manifest.json`.
7. Carga diferida (`loading="lazy"`, `decoding="async"`), `alt` descriptivo que diga «ilustración esquemática»
   (o `alt=""` si es decorativa), `prefers-reduced-motion` respetado.

## Verificación

`npm run typecheck`, `npx eslint apps/web/src/atlas`, `npx prettier --write` sobre lo tocado, `npm run test`.
