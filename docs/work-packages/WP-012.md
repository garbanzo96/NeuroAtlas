# WP-012: Cotejar el modelo HH con el artículo original y revisión computacional

- **Hito:** M2 · **Ejecutor recomendado:** R (cotejo) + H (asesor de neurociencia computacional) + C (integración)
- **Depende de:** acceso al artículo (Hodgkin & Huxley 1952, J Physiol 117:500–544) · **Tamaño:** M

## Objetivo

Verificar contra el artículo original las ecuaciones, constantes, parámetros, convenciones, especie y temperatura
de `content/models/hh-classic.yaml`, y registrar la revisión de un especialista.

## Contexto

La implementación coincide con NEURON 9.0.2 (ADR-0006), lo que verifica la ejecución y la transcripción que
comparten ambas, pero no el cotejo con la fuente primaria. Todos los `locator` de parámetros son `pending` y la
especie del contexto (`Loligo forbesii`) proviene de literatura secundaria.

## Archivos

- Leer: `content/models/hh-classic.yaml`, `content/contexts/visual-unit.yaml` (contexto HH),
  `content/claims/hodgkin-huxley.yaml`, `packages/simulation/src/models/hh-classic.ts`,
  `tools/reference/hh_neuron_reference.py`.
- Modificar: los tres YAML anteriores (localizadores, correcciones), y solo si hay discrepancias:
  `hh-classic.ts` + regenerar la referencia NEURON + pruebas.
- Crear: `docs/research/evidence/WP-012.md`.

## Pasos sugeridos

1. Para cada parámetro y ecuación: ecuación/tabla/página del artículo; anotar la convención original
   (V como desplazamiento con signo opuesto) y comprobar la conversión documentada en `conventions`.
2. Verificar especie y temperatura de la preparación; corregir el contexto si procede.
3. El asesor revisa ficha, supuestos, límites y la explicación al usuario; el usuario registra en
   `reviews` una entrada `kind: human_expert` con alcance y resultado.
4. Si algo cambia en las ecuaciones: actualizar implementación, regenerar la referencia
   (`python tools/reference/hh_neuron_reference.py > packages/simulation/src/fixtures/hh-neuron-reference.json`)
   y explicar el cambio en un ADR.

## Criterios de aceptación

- Cada parámetro con `locator` concreto; `locatorVerified: true` solo tras verificación humana.
- `docs/research/evidence/WP-012.md`: tabla parámetro/ecuación → localizador → coincide (sí/no) → nota.
- `npm run check` en verde (incluida la comparación con NEURON).
- El estado del modelo solo cambia a `reviewed` si hay revisión `human_expert` aprobada (el validador lo exige).
