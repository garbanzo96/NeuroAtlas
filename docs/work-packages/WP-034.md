# WP-034: Auditoría de accesibilidad automatizada (axe) y correcciones

- **Hito:** M4 · **Ejecutor recomendado:** M · **Depende de:** — · **Tamaño:** M

## Objetivo

Comprobar automáticamente en CI que no hay infracciones de accesibilidad graves o críticas en las cinco escenas,
el recorrido guiado y el diálogo de atajos, y corregir las que aparezcan.

## Archivos

- Leer: `AGENTS.md`, `e2e/app.spec.ts`, `playwright.config.ts`, `apps/web/src/components/*`, `apps/web/src/styles.css`.
- Crear: `e2e/a11y.spec.ts`.
- Modificar: componentes y estilos necesarios para corregir; `package.json` raíz (devDependency **autorizada**:
  `@axe-core/playwright`).
- No tocar: contratos, contenido, lógica de simulación.

## Requisitos

- Una prueba por escena (`/?s=<sceneId>`), una con el recorrido guiado activo y otra con el diálogo `?` abierto.
- Fallar ante infracciones `serious` o `critical`; listar las `moderate` en la salida.
- El canvas WebGL puede excluirse del análisis (no es HTML), pero no su contenedor ni los controles.
- Correcciones mínimas: contraste, nombres accesibles, roles, orden de encabezados, foco.

## Criterios de aceptación

- `npx playwright test e2e/a11y.spec.ts` sin infracciones serias/críticas.
- Las pruebas e2e existentes siguen pasando; `npm run check` en verde.
- En el PR: lista de infracciones encontradas y cómo se corrigió cada una.

## Prompt para copiar

```text
Realiza únicamente WP-034 de NeuroAtlas siguiendo AGENTS.md y docs/work-packages/WP-034.md (adjuntos con los
archivos de "Leer"). Añade @axe-core/playwright como devDependency raíz, crea e2e/a11y.spec.ts con las pruebas
indicadas y corrige las infracciones serias/críticas con cambios mínimos. No cambies contenido ni contratos.
Ejecuta npm run check y npx playwright test; entrega diff, lista de infracciones y salida de las pruebas.
```
